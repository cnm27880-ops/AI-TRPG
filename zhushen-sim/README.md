# 主神空間主管模擬器

養成管理模擬器 (Raising / Management Simulator)。你是被主神壓榨的主管，管一群輪迴者，派他們下副本賺積分。

- 完整設計：[`docs/GAME_DESIGN_PLAN.md`](docs/GAME_DESIGN_PLAN.md)
- 這個資料夾是**獨立的新專案**，跟外層的舊 AI-TRPG 專案互不相干（不共用任何程式碼）。
- 純前端（HTML / CSS / JavaScript），**不需要安裝任何套件**，也不需要後端或 API 金鑰。

## 怎麼在自己的電腦上玩（Windows 詳細步驟）

因為遊戲用了 ES 模組 (ES Modules)，**直接雙擊 `index.html` 是打不開的**（瀏覽器的安全限制），要先開一個本機伺服器：

1. 確認電腦有安裝 Node.js（版本 18 以上）。打開「終端機」（按 `Win` 鍵，輸入 `powershell`，按 Enter），輸入：
   ```
   node -v
   ```
   有出現 `v22.x.x` 之類的版本號就代表有裝。沒有的話到 https://nodejs.org 下載 LTS 版安裝。
2. 在終端機用 `cd` 進到這個資料夾，例如：
   ```
   cd C:\你放專案的路徑\AI-TRPG\zhushen-sim
   ```
3. 啟動伺服器：
   ```
   npm start
   ```
   看到 `主神空間主管模擬器：http://localhost:5173` 就成功了。
4. 打開瀏覽器，網址列輸入 `http://localhost:5173`。
5. 不玩了：回到終端機按 `Ctrl + C` 關掉伺服器。

存檔放在瀏覽器的 localStorage，每天結算時自動存。要重來：⚙️ 設定 →「刪除存檔並重新開始」。

## 設計問題（已由露葵確認）

計畫書沒寫、或寫法有歧義的地方，Phase 1 先填了暫定值（全部集中在 `src/data/config.js`，改一個數字就能調）。**2026-11-13 露葵確認：以下 10 項全部採用，其中第 3 項改為 150、第 4 項確認為範圍值。**

1. **通關條件**：計畫第 5.8 節寫「5 個房間都通過才通關」，但每間 70% 的話，戰力剛好達標的隊伍通關率只有 17%（0.7⁵），而且計畫又寫「失敗時隨機一人受傷」沒說是否中斷。暫定為「**5 間通過 3 間以上算通關**，失敗的房間有人受傷但隊伍繼續走」（達標隊伍通關率約 84%）。設定值：`dungeon.roomsToClear`。
2. **帶傷出征的死亡率加成**（+20% / +50% / +80%）：暫定為「帶傷出征的人**被打中時**，先擲一次直接死亡」。
3. **開局積分**：**150**（已確認，原暫定 300）。
4. **各階級的戰力**：範圍值，已確認 C 34~42、B 42~54、A 68~84、S 105~135。
5. **隊伍人數上限**：暫定 4 人。
6. **可以借錢抽卡嗎**：暫定可以（積分花到 -500 為止），因為計畫說高利貸是為了防止卡死。
7. **債務頂到 -500 還付不出維持費**：暫定主神電擊全員。
8. **遊戲結束條件**：暫定「沒有任何輪迴者，而且借不到錢抽最便宜的卡池」。
9. **回收爐**：暫定任何在主神空間的輪迴者都能回收，其他人理智 -5。
10. **理智歸零會怎樣**：Phase 1 只記錄數字，沒有效果（發瘋屬於 Phase 2 事件）。

# 主神空間主管模擬器 — 遊戲設計計畫（初稿）

> **工作標題**：主神空間主管模擬器（暫定，可改名）
> **遊戲類型**：養成管理模擬器（Raising / Management Simulator）
> **開發方式**：開新專案，不修改舊 AI-TRPG 專案（舊專案是無限恐怖 TRPG，底層邏輯完全不同）
> **目標平台**：網頁（HTML / CSS / JavaScript）
> **設計日期**：2026-11-13
> **設計者**：露葵（企劃）+ 蘇爾（PM）

---

## 1. 遊戲概述

### 1.1 一句話介紹

玩家扮演被主神壓榨的主神空間主管，管理一群輪迴者，派他們去副本送死，靠他們帶回來的積分維持主神空間運作，同時處理他們的八卦、恩怨、戀愛、生小孩。

### 1.2 核心特色

- **不是傳統無限恐怖**：沒有「每七天一定要下一次副本」的強制期限，時間一直自動跑，玩家自己決定要不要派人去副本。
- **養成遊戲**：重點是培養輪迴者、看他們成長、看他們談戀愛生小孩、看他們互相陷害，不是親自下去打怪。
- **狗血八卦生產器**：參考《某某宗女修修煉手札》跟《修仙門派模擬器》的事件引擎，輪迴者會在主神空間裡自己搞出各種狗血劇情。
- **死亡是永久的**：輪迴者死了就是死了，不會復活，但是帳號的積分跟解鎖會保留下來。

### 1.3 目標玩家

喜歡模擬器、Roguelike、狗血劇情的玩家。喜歡看小人自己搞事，不喜歡一直操作。

## 2. 核心循環（Game Loop）

```
主神空間休整（時間自動跑，小人走來走去，觸發關係事件、許願事件）
    ↓
玩家決定：手動派遣 或 自動派遣
    ↓
副本自動進行（小人走過一個一個房間，日誌刷出戰鬥結果）
    ↓
結算：活著的帶積分回來，死了的永久消失
    ↓
玩家花積分：抽卡、買東西、滿足願望、簽員工合同
    ↓
回到主神空間休整（循環）
```

### 2.1 時間系統

- 時間一直自動跑，不需要玩家按下一天。
- 速度控制：1x / 2x / 5x / 10x，玩家可以隨時調整。
- 自動暫停：遇到關鍵事件時，遊戲自動暫停，等玩家做決定。
  - 輪迴者許願的時候（許願有時間限制）
  - 有人死掉的時候
  - 有人生小孩的時候
  - 主神給任務的時候
  - 關係有重大變化（告白、黑化、背叛）
  - 商店開新階級的時候
- 玩家可以自訂哪些事件要暫停、哪些不要。

**副本與主神空間的時間同步（MVP 用方案 A）**：

- 進副本時，畫面切換到「副本模式」，主神空間暫停。
- 副本有 5 個房間（進度 20%、40%、60%、80%、100%）。
- 每走一個房間，算作主神空間過去了 0.2 天。
- 打完一場副本（5 個房間），剛好等於主神空間過了 1 天，扣留守人員 1 天的維持費。
- 這樣時間軸就很清楚，不會有雙軌同步的問題。

（未來可以考慮方案 B：雙視窗同步，畫面下方顯示副本進度條，副本跑 2 天，主神空間的人繼續活動。但是 MVP 先用方案 A，比較簡單。）

### 2.2 派遣系統

**手動派遣**：玩家自己選哪幾個輪迴者去哪個副本。

**自動派遣**：系統自動計算每個輪迴者去每個副本的成功率，自動派最適合的那一組去。規則：
- 考慮戰力、標籤、環境相性。
- 戰力低的優先派去簡單副本，戰力高的優先派去困難副本，不浪費戰力。
- 玩家可以隨時切換手動 / 自動。

**自動派遣保護開關（防止 SSR 寶貝被自動送死）**：

- [v] 禁止自動派遣受傷人員（受傷的人不會被自動派出去）。
- [v] 禁止將【仇恨 / 死敵】編入同一隊（有仇的兩個人不會被自動編在一起）。
- 每個輪迴者可以點一個「🔒 鎖定」按鈕，鎖定後就不參與自動派遣，專門留在家裡休息、配種、生小孩。
- 這些開關預設都是開啟的，玩家可以自己關掉。

## 3. 輪迴者系統

### 3.1 生成

- 開場送 3 個隨機生成輪迴者。
- 之後靠抽卡獲得（見第 11 節）。
- 小孩也是一種獲得方式（見第 7 節）。

### 3.2 屬性

- 生命（HP）
- 戰力（攻擊力）
- 防禦
- 速度 / 閃避
- 理智（精神狀態，太低會發瘋）
- 運氣

### 3.3 標籤

每個輪迴者身上有 **4-5 個標籤**：
- 2 個基礎數值標籤（例如：天生神力、皮糙肉厚、身輕如燕）
- 1-2 個性格機制標籤（例如：恐怖片作死專家、薪水小偷轉世、綠茶）
- 1 個靈魂核心標籤（SR / SSR / UR 級，例如：痛覺轉化、烏鴉嘴、借運人）

標籤決定輪迴者的個性、能力、行為模式，也決定他會觸發什麼事件。

### 3.4 死亡

- 死亡是永久的，不會復活。
- 死亡時會掉落裝備 / 血統 / 積分（具體數字待定）。
- 死亡會觸發連鎖反應（見第 6.4 節）。

### 3.5 傷勢系統

**傷勢分級**：

| 等級 | 休息時間 | 每日額外花費 | 派出去死亡率加成 |
|------|----------|--------------|------------------|
| 輕傷 | 1 天 | +5 分 | +20% |
| 重傷 | 3 天 | +15 分 | +50% |
| 致命傷 | 7 天 | +30 分 | +80% |

**傷勢怎麼來**：
- 成功率越低的副本，越容易受傷。
- 首次開荒（沒有情報）的副本，很容易受傷。
- 就算通關成功了，還是有可能帶傷回來。
- 副本失敗但是活著回來，一定會受傷。

**傷勢沒好就派出去**：
- 玩家可以選擇讓受傷的輪迴者休息，也可以賭一把直接派出去。
- 派出去的話，死亡率上升（見上表），而且傷勢有可能惡化：
  - 輕傷 → 重傷
  - 重傷 → 致命傷
  - 致命傷 → 直接死掉
- 但是如果他活著回來了，有機會獲得【身經百戰】之類的獎勵標籤。

**治療方式**：
- 在主神空間休息（花時間 + 每天的維持費）。
- 用藥水 / 道具治療（花積分，立即或加速恢復）。
- 某些標籤可能治療比較快（例如：醫療背景）。

## 5. 副本系統

### 5.1 總數

計畫 20 個副本，MVP 先做 3 個。全部都是原創世界，學電影的感覺跟類型，但是內容全部原創，避免版權問題。

### 5.2 MVP 3 個副本

**副本一：中國風落後村莊（靈異）— 簡單**
- 主題：中國農村、霧、祖先祠堂、紙紮人、餓鬼。
- 氛圍：陰森、迷信、鄉土恐怖。
- 適合測試標籤：凶宅試睡員、恐怖片作死專家。
- 特殊獎勵：鬼道術法、符咒、陰陽眼。

**副本二：太空船失去動力有怪物（科幻）— 中等**
- 主題：太空船、失去動力、黑暗走廊、異形怪物。
- 氛圍：密閉、缺氧、科技恐怖。
- 適合測試標籤：末日囤積症、鍵盤軍事家、路痴。
- 特殊獎勵：科技改造、義體、外星武器。

**副本三：魔法戰爭（奇幻）— 困難**
- 主題：魔法風暴、敵對法師、魔法生物、燃燒的城堡。
- 氛圍：史詩、混亂、魔法對轟。
- 適合測試標籤：痛覺轉化、借運人、烏鴉嘴、Flag 建築師。
- 特殊獎勵：魔法、魔杖、魔法血統。

### 5.3 副本特殊獎勵

每個副本都有自己的獨特掉落表，通關有機會獲得：
- 武俠本 → 武功
- 靈異村 → 鬼道術法
- 太空船 → 科技改造
- 魔法戰爭 → 魔法

這樣玩家就會想去不同的副本收集不同的東西，不會只打同一個副本刷積分。

### 5.4 副本環境標籤

每次進入副本，隨機抽環境標籤，讓同一個副本每次都不一樣。22 個環境標籤詳見 4 Argon 的檔案（例如：絕對靜音領域、鏡像反轉世界、強制直播秀、精神共享網絡、主神親自督戰）。

### 5.5 重打機制

重打已經通關的副本，成功率會變高，但是失敗還是會死。

### 5.6 首次開荒（First Clear）

**沒有情報**：第一次進入一個副本，因為沒有情報，所以：
- 成功率比較低。
- 受傷機率比較高。
- 不知道裡面有什麼怪物、什麼陷阱、什麼寶箱。

**豐富獎勵**：首次通關會給額外的豐富獎勵，吸引玩家去開荒：
- 多給 50 分（建議值）。
- 一定會掉一個特殊獎勵（血統 / 瞳術 / 技藝 / 武功 / 魔法）。
- 解鎖該副本的情報（之後再打就知道裡面有什麼）。

### 5.7 獎勵遞減（Diminishing Returns）

同一個副本一直刷，獎勵會越來越低，防止玩家無腦刷同一個簡單副本：

- 第 1 次（開荒）：150% 獎勵（100 分基礎 + 50 分開荒加成）。
- 第 2-3 次：120% 獎勵。
- 第 4-5 次：100% 獎勵（基礎值）。
- 第 6-10 次：80% 獎勵。
- 第 11 次以後：60% 獎勵（地板價，不會再低）。

地板價的設計：獎勵只夠勉強跟每天的維持費打平，玩家不虧錢，但是也賺不到錢，一定要去開荒新副本或是打更難的副本才能賺錢。

（以上數字是建議值，可調整。）

### 5.8 成功率公式（給小克的數學底子）

每個副本有 5 個房間（進度 20%、40%、60%、80%、100%）。

**每個房間檢定一次**：

```
房間通過率 = (小隊總戰力 / 副本推薦戰力) × 基礎 70% + 關係加成 + 標籤與環境相性
```

- 小隊總戰力：出戰的所有輪迴者戰力加總。
- 副本推薦戰力：每個副本有一個推薦戰力數字（例如：簡單 100、中等 200、困難 400）。
- 基礎 70%：就算戰力剛好等於推薦戰力，通過率也只有 70%，不是 100%。
- 關係加成：喜歡 +10%、愛慕 +20%、討厭 -10%、仇恨 -20%（見第 6.3 節）。
- 標籤與環境相性：例如恐怖片作死專家在靈異副本 +15%、路痴在迷宮環境 -15%。

**如果房間檢定失敗**：
- 隨機一名隊員受傷（輕傷 → 重傷 → 致命傷 → 死亡）。
- 傷勢等級看失敗的嚴重程度（隨機決定）。

**如果 5 個房間都通過**：
- 副本通關成功，獲得獎勵（見第 5.6、5.7 節）。
- 但是還是有可能帶傷回來（見第 3.5 節）。

這樣就把「副本過程、傷勢系統、標籤事件、關係加成」完美串在一條公式上了。

（以上數字是建議值，可調整。）

## 6. 關係系統

### 6.1 關係數值

每個輪迴者之間有一張關係表：
- 好感度（0-100）：越高越喜歡對方。
- 仇恨值（0-100）：越高越討厭對方。
- 特殊狀態：戀人、死敵、師徒、債主、靈魂伴侶等。

### 6.2 關係觸發

當 2 個以上輪迴者待在主神空間時，隨機觸發關係事件：
- 一起吃飯、一起訓練、吵架、搶東西、偷東西、告白、背叛。

### 6.3 關係效果

- 喜歡（好感 50-79）：一起出戰 +10% 成功率。
- 愛慕（好感 80+）：一起出戰 +20% 成功率，會互相保護。
- 討厭（仇恨 50-79）：一起出戰 -10% 成功率。
- 仇恨（仇恨 80+）：一起出戰 -20% 成功率，可能在副本裡互相陷害。
- 靈魂伴侶：一起出戰大加成，但是一人死了另一人會崩潰（屬性大跌或黑化）。
- 死敵：會在副本裡互相殘殺，不打怪先打對方。

### 6.4 死亡連鎖反應

輪迴者死掉的時候，會引發一連串反應：
- 死者的戀人 / 死黨：擲骰決定三種反應之一：
- 悲憤交加，頓悟突破（全屬性 +30%）
- 道心破碎，一蹶不振（全屬性 -20%，獲得標籤）
- 走火入魔（獲得或標籤）
- 如果死者是被隊友害死的，死者的戀人 / 死黨對兇手自動鎖定，下次編在同一隊進副本，第一回合不打怪，直接自相殘殺。
- 功德無量笑面虎會去偷死者的遺產，全屬性永久 +10%。
- 其他輪迴者會開始害怕下一個死的是自己。

### 6.5 標籤影響關係

- 瘋狂月老：加速戀愛事件觸發。
- 綠茶 / 心機蓮花：製造修羅場，讓別人吵架。
- 功德無量笑面虎：會偷死者遺產，沒人喜歡他。
- 背刺成癮者：容易在副本裡背刺隊友。

### 6.6 主神空間暴力規則（借刀殺人）

**直接動手殺人會被主神懲罰**（學原著《無限恐怖》的設定）：
- 扣 500 分（建議值）。
- 或是把兇手的某個標籤洗掉。
- 或是主神直接把兇手抹殺。
- 兇手不敢在主神空間裡面直接動手。

**借刀殺人是允許的，而且是最有趣的玩法**：
- 陷害別人：讓主神以為是他犯錯，主神就會懲罰他。
- 破壞裝備：偷偷破壞別人的裝備，讓他去副本的時候死掉。
- 騙去送死：騙別人去打他打不過的副本。
- 下毒：食物裡面下毒，但是裝成是意外。
- 散播謠言：讓其他人討厭他、孤立他、聯手對付他。
- 在副本裡：背刺、見死不救、把怪物引到隊友身邊、搶隊友的寶箱。

**主神空間 vs 副本的規則對比**：
- 主神空間：壓抑著不敢動手，只能耍陰招、借刀殺人。
- 副本：徹底放開來亂殺，沒有主神在看，想怎麼殺就怎麼殺。
- 這個對比很有張力，玩家跟輪迴者都要動腦筋，不是直接拿刀砍人就好。

## 7. 生小孩系統

### 7.1 輪迴者之間生小孩

- 關係很好的輪迴者（愛慕 / 靈魂伴侶）有機會生小孩。
- 不需要員工合同，因為他們本來就是主神空間的人。
- 小孩直接成為新的輪迴者，免費獲得。

### 7.2 輪迴者跟副本 NPC 生小孩

- 輪迴者在副本裡跟 NPC 談戀愛、生小孩。
- 小孩要帶回主神空間，需要員工合同（見第 8 節）。
- 輪迴者會向管理者許願，想要把小孩帶回來。

### 7.3 小孩標籤繼承

- 小孩大部分繼承父母的標籤。
- 也有可能繼承父母從副本裡學到的東西（血統、瞳術、技藝、武功、魔法）。
- 副本 NPC 本來就比普通輪迴者厲害，所以跟 NPC 生的小孩也會比較強。
- 這會讓玩家很想配種，故意讓強的輪迴者跟副本裡的厲害 NPC 生小孩。

### 7.4 主神催熟艙（避免嬰兒提刀上陣）

- 嬰兒出生後，不會直接變成輪迴者，會被放進「主神基因催熟艙」3 天。
- 催熟期間：每天只吃 5 分維持費，頭頂顯示 🍼 emoji，不能派去副本。
- 3 天時間一到，系統彈出提示：「催熟完成！小孩已長成 18 歲青壯年，並繼承了父母的【痛覺轉化】與【鬼道術法】！」
- 催熟完成後，小孩直接變成可用的輪迴者，可以派去副本。
- 這樣既合理化了時間，又保留了配種的爽感，主神空間不養閒人，連嬰兒都要快速長大去打工。

## 8. 員工合同

### 8.1 是什麼

一種道具，專門用來把副本人物帶回主神空間當輪迴者。名字取自原著的奴隸契約，改成員工合同，符合「主神壓榨主管、主管壓榨輪迴者」的黑色幽默。

### 8.2 使用時機

- 輪迴者在副本裡遇到讓他心動的對象，想要把對方帶回來。
- 輪迴者跟副本 NPC 生了小孩，想要把小孩帶回來。
- 輪迴者會向管理者許願，想要一張員工合同。

### 8.3 取得方式

- 商店購買（價格待定）。
- 主神任務獎勵。
- 副本掉落（稀有）。

## 9. 許願系統

### 9.1 是什麼

輪迴者會主動跑來跟管理者許願，想要什麼東西。

### 9.2 許願種類

- 想要吃好的（食物）
- 想要去某個副本
- 想要跟某個人組隊
- 想要放假（休息幾天）
- 想要某件裝備 / 道具
- 想要一張員工合同（帶 NPC 或小孩回來）
- 想要跟某個人結婚 / 生小孩

### 9.3 時間限制

- 每個許願都有時間限制，超過時間自動算失敗。
- 時間限制內滿足 → 輪迴者很高興，很有幹勁（屬性暫時提升、成功率提升）。
- 時間限制內不滿足 / 超過時間 → 輪迴者很不爽（屬性暫時下降、可能擺爛、可能叛逃、可能在副本裡故意送死）。

### 9.4 跟事件引擎整合

許願系統接進時間 Tick 系統裡面，每個 Tick 系統先檢查有沒有輪迴者要許願，有的話就彈出來給玩家看，遊戲自動暫停，等玩家決定。

## 10. 商店系統

### 10.1 分階

商店分 4 個階級，靠玩家累積花費的積總量解鎖：

- Tier 1（花 0 積分）：基本藥水、基本武器、基本防具。
- Tier 2（花 500 積分）：D 級血統、技能、比較好的裝備。
- Tier 3（花 2000 積分）：C / B 級血統、瞳術、技藝。
- Tier 4（花 5000 積分）：A / S 級血統、傳說裝備、特殊道具。

（以上數字是建議值，可調整。）

### 10.2 賣什麼

- 強化：加攻擊、防禦、生命、速度。
- 血統：吸血鬼、狼人、龍、惡魔等。
- 瞳術：寫輪眼、白眼、輪迴眼等（各種類型的眼睛能力）。
- 技藝：劍術、醫術、鍛造、烹飪等。
- 道具：藥水、武器、防具、員工合同。
- 技能：新能力（主動 / 被動）。

## 11. 抽卡系統

### 11.1 卡池

- **B~A 池**：150 分抽一次（70% B、30% A）。
- **A~S 池**：400 分抽一次（70% A、30% S）。
- 純隨機，不加保底。玩肉鴿的玩家都很 M，符合殘酷調性。

（以上數字是建議值，可調整。）

### 11.2 通關獎勵

- 簡單副本：100 分。
- 中等副本：200 分。
- 困難副本：400 分。

這樣打一個簡單副本就能抽一次便宜的池子，打一個困難副本就能抽一次貴的池子，節奏剛好。

### 11.3 新輪迴者標籤

抽到的新輪迴者有 4-5 個標籤（見第 3.3 節），稀有度照第 4.2 節的機率。

## 12. 主神壓力系統

### 12.1 設計原則

**沒有強制下副本的期限**。不像傳統無限恐怖「每七天一定要下一次副本，不去就死」，這個遊戲的壓力來自經濟跟主神的無聊，不是倒數計時。

### 12.2 經濟壓力

- 主神空間每天都要花積分維持運作（房租、水電、食物）。
- 輪迴者每天都要吃飯。
- 員工合同要花錢買。
- 玩家不派人去副本賺積分，遲早會破產。

**每日維持費計算**：

每個輪迴者每天消耗的積分 = 基礎 10 分 + 階級加成 + 傷勢加成

| 階級 | 加成 |
|------|------|
| C 級 | +0 分 |
| B 級 | +5 分 |
| A 級 | +10 分 |
| S 級 | +20 分 |

| 傷勢 | 加成 |
|------|------|
| 無傷 | +0 分 |
| 輕傷 | +5 分 |
| 重傷 | +15 分 |
| 致命傷 | +30 分 |

**範例**：
- C 級無傷：10 分 / 天。
- B 級輕傷：10 + 5 + 5 = 20 分 / 天。
- A 級重傷：10 + 10 + 15 = 35 分 / 天。
- S 級致命傷：10 + 20 + 30 = 60 分 / 天。

**重要規則**：
- 只有輪迴者待在主神空間的時候才要花維持費。
- 輪迴者在副本裡探索的時候，不需要花維持費。
- 這樣玩家就不能一直讓輪迴者待在主神空間裡面談戀愛生小孩，一定要派他們去副本賺積分。
- 待在主神空間可以休息恢復、可以談戀愛、可以生小孩，但是每天都要花錢，這個取捨很有意思。

（以上數字是建議值，可調整。）

### 12.3 主神無聊壓力

主神如果覺得無聊，會隨機搞事：
- 突然把某個輪迴者變成怪物。
- 突然要求玩家上繳 500 積分，不給就扣東西。
- 突然指定某個輪迴者去打某個副本，不去就懲罰。
- 突然給玩家一個限時任務，完成有獎勵，失敗有懲罰。

### 12.4 主神主動干預事件

主神不只是背景設定，是一個真的會搞事的角色：
- 覺得某個輪迴者太廢了，直接降下一道雷劈他。
- 覺得某兩個輪迴者太恩愛了，故意派他們去同一個必死的副本，想看他們誰會先背叛誰。
- 覺得玩家太閒了，丟一個超難的任務過來。

### 12.5 破產與壓榨方案（防止卡死 Soft-lock）

**問題**：開場 3 個 C 級輪迴者，一天維持費 30 分。如果玩家第一次打簡單副本失敗了，3 個人都受了重傷（休息 3 天，每人每天 25 分），那這 3 天就要扣 225 分。如果玩家開場積分不夠，或者連敗兩次，積分歸零又沒人能打贏副本，遊戲就會直接卡死（無法抽卡、無法治傷）。

**解決方案一：主神高利貸**：
- 積分可以變成負數（上限 -500 分）。
- 負債期間，主神每天會隨機「電擊」一名輪迴者（理智 -10）。
- 或者主神強制沒收一件裝備抵債。
- 玩家要趕快賺積分還債，不然輪迴者會越來越瘋。

**解決方案二：主神回收爐（賣器官 / 解雇）**：
- 如果某個輪迴者受了致命傷（每天要吃 40-60 分，要養 7 天），玩家算一算發現養活他要花 300 分，還不如直接花 150 分抽個新的。
- 這時允許玩家把重傷員直接推進【主神回收爐】，做成營養液或是直接解雇。
- 回收可以換取 30 積分，並省下醫藥費。
- 但是會導致其他輪迴者理智下降，或是對主管產生恐懼（「下一個會不會就是我？」）。
- 超有惡德主管的感覺，完全符合黑色幽默。

（以上數字是建議值，可調整。）

## 13. 事件引擎

### 13.1 底層邏輯（參考修仙門派模擬器）

來自 4 Argon 的分析（《某某宗女修修煉手札》跟《修仙門派模擬器》共用的底層引擎）：

**時間脈衝（Time Tick）**：遊戲以「天」為一個結算單位，每跳一個時間單位，系統把所有輪迴者排隊抓出來過一次篩子。

**擲骰決定動作**：
- 50% 機率：執行日常工作（健身、包紮、喝咖啡，單純加減一點點數值）。
- 30% 機率：找另一個人互動（系統隨機抓一個人出來，檢查好感度跟標籤）。
- 20% 機率：觸發特殊個人事件（檢索身上的特殊標籤）。

**條件判定公式**：IF（如果）... THEN（就）...
- 例如：IF A 對 B 的愛慕值 > 80 AND B 對 A 的愛慕值 < 20 AND A 有標籤 AND A 的武力值 > B 的武力值，THEN A 把 B 打暈帶回密室囚禁，B 變成狀態，玩家必須派人去救。

**事件鏈（Event Chain）**：大事件分成三個階段，不會一次結束。
- 階段一：撿到寶（獲得隱藏標籤）。
- 階段二：甜頭期（連續觸發好事件，屬性大增）。
- 階段三：收網（奪舍 / 背叛 / 黑化）。

**字串拼接（String Template）**：用 Mad Libs 填空題模板寫事件。
- 只需要寫 50 個事件骨架，讓標籤去替換裡面的動作跟結果。
- 例如：骨架是「[角色A] 與 [角色B] 在餐廳因為搶奪最後一塊肉發生了爭執，[角色A的反應]，導致 [事件結果]」，系統根據 A 的標籤填入不同的反應跟結果。

### 13.2 主神空間專屬優化

**剝削鏈事件**：主神壓榨主管 → 主管壓榨輪迴者 → 輪迴者壓榨更弱的輪迴者 → 最弱的崩潰，在副本裡故意害死隊友。一環扣一環。

**許願系統整合**：許願接進 Tick 系統，每個 Tick 先檢查有沒有人要許願。

**死亡連鎖**：死亡不只是少一個人，會引發復仇、繼承、黑化、恐慌（見第 6.4 節）。

**小人動畫跟日誌連動**：事件發生時，小人要真的動起來（見第 14 節）。

**AI 寫變體文字**：同一個事件骨架，用 AI 事前寫出 3-5 個不同版本存在資料庫，遊戲執行時隨機抽一個版本，玩家看到同一個事件，文字每次都不一樣，但是邏輯跟數值都是一樣的。

**事件冷卻跟記憶**：每個事件加冷卻時間，同一個事件在 7 天內不要重複出現，系統記住哪些事件已經發生過了，優先觸發還沒出現過的事件。

### 13.3 三張表

遊戲只需要做好這三張表：

1. **角色狀態表**：[生命, 戰力, 理智, 標籤1, 標籤2, 標籤3, 標籤4, 標籤5]
2. **關係矩陣表**：[A對B的好感, A對B的仇恨, A對B的特殊狀態]
3. **事件觸發器（Trigger）**：每天跑一次 IF（關係 + 標籤 + 戰力對比）THEN 印出文字並修改數值。

## 14. 視覺呈現

### 14.1 風格：監獄模擬器

參考《監獄模擬器》（Prison Architect）的風格：
- 主神空間本來就是監獄，輪迴者就是囚犯，玩家就是典獄長。
- 簡單的俯視圖、房間分區、小人在裡面走來走去。
- 重點是管理，不是畫面。

### 14.2 主神空間畫面

- 白色背景，乾淨、空靈。
- 幾個房間：宿舍、餐廳、訓練場、商店、傳送門。
- 迷你小人在房間之間走來走去。
- 吃飯去餐廳、睡覺回宿舍、想打架就衝去找對方。

### 14.3 迷你小人

- 風格：光遇（Sky: Children of the Light）風格，無面迷你小人，瘦長身體、圓圓的頭。
- **顏色統一**：不要每個標籤不同顏色，會太花。全部用同一個顏色（白色 / 淺灰）。
- **靠配件跟服飾區分**：恐怖片作死專家拿手電筒、BGM 自帶者頭上有音符、美食家戴廚師帽。
- **配件用 emoji**：🔦 🎵 ❤️ 😡 💤 ❗，不用畫圖。
- **表情符號**：頭頂冒出表情符號，戀愛中是 ❤️、生氣是 😡、睡覺是 💤、有願望是 ❗。
- **點一下小人**：可以看到詳細資料（標籤、屬性、關係、願望）。

### 14.4 動畫（MVP 簡化版）

- **不需要真正的走路動畫**：小人就是一張靜態圖片，在畫面上滑來滑去。
- 就像下棋一樣，棋子本身不會動，但是會從 A 點滑到 B 點。
- 網頁上用 CSS transition 就可以做到，改一下圖片的位置，加上平滑移動效果，程式碼十幾行。
- 互動的時候：兩個小人滑到一起，頭頂冒出對話框或是表情符號，配上右邊的日誌文字。
- 圖片用 AI 生成的，配件用 emoji，移動用 CSS，全部都是小克本來就會的東西。

### 14.5 副本畫面

- 一條直線的路線圖，小人從左邊走到右邊，經過一個一個房間。
- 每個房間刷出一條日誌，告訴玩家發生什麼事。
- 進度 20% 遇到怪物、50% 發現寶箱、80% 有人背刺隊友、90% 有人偷屍體。
- 畫面上的小人會移動，配上日誌的文字。

### 14.6 介面

- 左邊：主神空間俯視圖（小人走來走去）。
- 右邊：主神監控日誌（不斷往上滾動的事件文字）。
- 上面：積分、時間、速度控制（1x / 2x / 5x / 10x）、暫停按鈕。
- 下面：輪迴者列表、商店按鈕、抽卡按鈕、派遣按鈕。

## 15. 技術架構（PM 層級，不寫實作細節）

### 15.1 開新專案

- 不修改舊 AI-TRPG 專案，開一個全新的專案。
- 舊專案是無限恐怖 TRPG（主線節點、AI 自由生成、詳細戰鬥），新專案是管理模擬器（事件引擎、時間 Tick、關係矩陣），底層邏輯完全不同。
- 硬改舊專案要花很多時間刪舊系統，刪到最後只剩骰子跟角色數值，不如直接開新專案。

### 15.2 技術棧

- 網頁應用（HTML / CSS / JavaScript），跟幻境編年史一樣。
- 前端：顯示主神空間、迷你小人、日誌、介面。
- 後端 / 邏輯：事件引擎、時間 Tick、關係計算、抽卡機率、商店。
- 資料：標籤庫、事件模板、副本資料，存在資料庫或 JSON 檔案。

### 15.3 AI 用途

- **事前寫作**：輪迴者生成器、商店道具描述、副本背景介紹、事件文本，用 Gemini 4 Argon 批量寫好，存在資料庫。
- **現場生成**：只在關鍵時刻呼叫 AI（死亡場景、關係突破、主神對話），成本低但是感情深。
- **事件變體**：每個事件骨架用 AI 寫 3-5 個不同版本，存在資料庫，遊戲執行時隨機抽。

## 16. MVP 範圍（第一版要做的東西）

MVP 拆成 3 個階段（Milestones），分三批讓小克做，不要一次叫他把 20 個系統全部寫出來，成功率會比較高。

### Phase 1：骨架與經濟循環（先把賺錢 → 養人 → 抽卡跑通）

- [] 時間自動跑 + 速度控制（1x / 2x / 5x / 10x）+ 自動暫停
- [] 主神空間畫面（白色背景、5 個房間、迷你小人滑動）
- [] 抽卡系統（B~A 池、A~S 池、純隨機不保底）
- [] 每日維持費（基礎 + 階級 + 傷勢，待在主神空間才花費）
- [] 傷勢系統（輕傷 / 重傷 / 致命傷，休息時間，派出去風險）
- [] 3 個 MVP 副本（中國村、太空船、魔法戰爭）的「純數值自動派遣與結算」
- [] 派遣系統（手動 + 自動 + 保護開關）
- [] 破產與壓榨方案（主神高利貸 + 主神回收爐）

### Phase 2：靈魂 — 標籤與事件引擎

- [] 30 個 MVP 標籤（見第 4.3 節）
- [] 副本環境標籤（每次進副本隨機抽）
- [] 主神監控日誌（右邊滾動的事件文字，Mad Libs 填空模板）
- [] 關係系統（好感度、仇恨值、關係事件）
- [] 死亡系統（永久死亡 + 連鎖反應）
- [] 成功率公式（5 個房間，每個房間檢定一次）
- [] 首次開荒（無情報、高風險、豐富獎勵）
- [] 獎勵遞減（一直刷同一個副本，獎勵越來越低，直到地板價）
- [] 借刀殺人（主神空間直接殺人會被懲罰，間接殺人允許）
